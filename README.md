# ai-meadi-news

نظام أتمتة لنشر أخبار التقنية والتسريبات العاجلة باللغة العربية على Telegram، مع سجل تاريخي يمنع تكرار الأحداث ويصنف الأخبار عبر Gemini.

## المسارات

| المسار | الوظيفة | الجدولة |
| --- | --- | --- |
| النشرة اليومية | جلب RSS الحديثة، اختيار الخبر الأهم غير المكرر، إنشاء التقرير ونشره | يوميًا 16:00 بتوقيت الرياض، 13:00 UTC |
| رصد التسريبات | تقييم المرشحين العاجلين وتصنيف موثوقيتهم ثم نشرهم بتحذير واضح | كل ساعتين |
| الملخص الأسبوعي | تلخيص النشرة اليومية وعرض الأخبار المهمة التي لم تُختر | الاثنين 09:00 بتوقيت الرياض، 06:00 UTC |

## عمر الأخبار والسجل

لا يقبل النظام أخبار RSS بلا تاريخ قابل للتحقق أو أقدم من سبعة أيام. ويحذف السجل كل إدخال بعد مرور سبعة أيام حقيقية على `posted_at`. لا يُضاف الخبر إلى JSON إلا بعد نجاح Telegram.

يحفظ `news_bot/posted_history.json` العنوان والرابط والملخص والمصدر ومفتاح الموضوع والشركة والشهر التقريبي والنوع والمنتج والمنطقة والكلمات المفتاحية ووقت الإضافة وحالة السجل ورقم رسالة Telegram ورابطها عند الإمكان. وعند وجود تحديث جوهري تُحفظ أيضًا حقائق التحديث ورابطته بالحدث السابق.

قبل النشر، يقارن البرنامج المرشح داخل حلقة بكل عناصر JSON باستخدام الرابط وتشابه العنوان ومفتاح الموضوع، ثم يطبق مطابقة تامة للمتغيرات المعروفة مثل الشركة والتاريخ والنوع والمنتج والمنطقة. عند وجود الحدث نفسه يُلغى النشر، ولا يُسمح بتحديثه إلا إذا أعاد Gemini حقائق جديدة فعلية لم تُسجل سابقًا.

## سجل المرفوضات

يحفظ `news_bot/rejected_news.json` العناصر التي لم تُنشر مع العنوان والرابط والمصدر والملخص وسبب الرفض ومرحلة الرفض والتصنيف وتاريخ الرفض. تشمل الأسباب العناصر القديمة أو التي بلا تاريخ موثوق، الروابط أو العناوين الناقصة، التكرار في السجل أو داخل دفعة RSS، انخفاض الموثوقية، وعدم اختيار Gemini لها. يحتفظ النظام بهذا السجل 30 يومًا افتراضيًا، ويمكن تغييره من `REJECTED_RETENTION_DAYS`، بينما يبقى سجل الأخبار المنشورة على مدة الاحتفاظ التشغيلية الخاصة به.

## التصنيفات

القائمة مغلقة: `ذكاء اصطناعي`، `أمن سيبراني`، `برمجيات`، `أجهزة وعتاد`، `أنظمة تشغيل`، `تطوير وبرمجة`، `سحابة ومراكز بيانات`، `أعمال وتقنية`، `خصوصية وبيانات`، `أخرى`.

## الملخص الأسبوعي

يشغّل `.github/workflows/weekly_summary.yml` الملف `news_bot/weekly_summary_main.py`. يقرأ الأخبار اليومية المنشورة والمرشحين المهمين غير المختارين من السجل، ثم يطلب من Gemini إنتاج جزأين نصيين. يسمح النظام بنحو 3900 حرف لكل جزء، ويقسم أي نص أطول ضمن حد Telegram البالغ 4096 حرفًا.

## الأسرار المطلوبة

أضف القيم التالية إلى **Settings → Secrets and variables → Actions**:

| المتغير | الاستخدام |
| --- | --- |
| `GEMINI_API_KEY` | التحليل والتصنيف والصور الاحتياطية |
| `TELEGRAM_BOT_TOKEN` | Telegram Bot API |
| `TELEGRAM_CHAT_ID` | قناة النشر الافتراضية |
| `LEAK_TELEGRAM_CHAT_ID` | اختياري لقناة التسريبات |

## التشغيل والاختبار

```bash
python -m pip install -r requirements.txt
cd news_bot
python main.py
python leaks_main.py
python weekly_summary_main.py
```

لتشغيل الاختبارات:

```bash
python -m unittest discover -s tests -v
```
